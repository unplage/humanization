# AGENTS.md

Antibody humanization pipeline (CDR grafting + back-mutation/回复突变 scoring, Fab and VHH).
Portable core is **pure Python stdlib** — do not add third-party deps for core paths.

## Commands

Run from repo root:

```bash
# humanize a FASTA (VH+VL in one file, or a single VHH chain)
python3 scripts/humanize/cli.py run --input data/examples/mouse_4d5_fab.fasta --outdir outputs

# check available tools (all optional; portable mode is fully functional)
python3 scripts/humanize/cli.py setup-check

# empirical calibration from KD experiments, then use with --calibration
python3 scripts/humanize/cli.py learn --experiments experiments.json --out calibration.json

# download NCBI IgBLAST germline (writes data/germline/human_gl_*.fasta, gitignored)
python3 scripts/humanize/cli.py setup-germline
```

Tests are plain scripts (pytest is NOT installed; each exits nonzero on failure):

```bash
python3 tests/test_pipeline.py      # ~75 unit checks
python3 tests/backtest.py           # 4D5→trastuzumab, A4.6.1→bevacizumab, VHH gold standard
python3 tests/backtest_scale.py     # HumAb25: 25 approved mouse antibodies
```

## Standard workflow (三步走) — always follow for humanization requests

1. **Step 1 — germline 策略对比**: run the pipeline once per strategy with distinct outdirs (same-name outputs are overwritten otherwise), then show the user a comparison table (chosen germline, FR/CDR identity, back-mutation counts) and ask which strategy to use:

   ```bash
   for s in fr_best cdr_best composite cvi_best min_backmutations current adimab_frequency pioneer_frequency composite_3axis; do
     python3 scripts/humanize/cli.py run --input <seq.fasta> --germline-strategy "$s" --outdir "outputs/strategy_$s" >/dev/null
   done
   ```

   9 个底层策略: `fr_best` | `cdr_best` | `composite` (0.7*FR+0.3*CDR) | `cvi_best` (canonical+vernier+interface) | `min_backmutations` | `current` (top-30% FR with max CDR) | `adimab_frequency` | `pioneer_frequency` | `composite_3axis` (0.5*CVI+0.3*freq+0.2*FR)。
   `auto` 是默认路由策略（VH=cvi_best, VL=cdr_best），不需要单独跑。

   **每个策略必须返回 5 个候选**（按评分排序，分数相同时按使用频率排序），格式示例：
   ```
   策略: fr_best
   #   V基因              FR     CDR    Composite  CVI    Freq   3axis   回突变
   1   IGHV3-72*01       0.867  0.440  0.739      0.833  0.003  0.591   1
   2   IGHV3-73*01       0.853  0.600  0.777      0.833  0.003  0.588   2
   3   IGHV3-73*02       0.853  0.600  0.777      0.833  0.003  0.588   2
   4   IGHV3-15*01       0.840  0.480  0.732      0.792  0.003  0.565   1
   5   IGHV3-15*02       0.840  0.480  0.732      0.792  0.003  0.565   1
   ```

2. **Step 2 — 按选定 germline 正式运行**: rerun once with `--germline-strategy <chosen> --outdir outputs` (or lock exact genes with `--force-germline H=IGHV1-3*01 L=IGKV1-39*01`) and deliver the full report set (markdown/docx/json/csv/fasta).

3. **Step 3 — 结构优化 (optional)**: if the user has an AF3 donor structure (PDB/CIF) or can run AF3, rerun with `--donor-structure <pdb>` (and/or `--af3-mode local --af3-binary <run_alphafold.py> --antigen <seq>`) so buriedness/contact/CDR-RMSD refine back-mutation scores; then diff before/after reports (tier changes, exposed-vs-buried reclassification) and summarize what the structure changed.

## Architecture

- Entry: `scripts/humanize/cli.py` → `pipeline.py` (`run_pipeline`); all core logic in `scripts/humanize/*.py`.
- Key modules: `numbering.py` (anchor-based Kabat, zero-dependency), `germline.py` (bundled JSON fallback + NCBI FASTA preferred), `graft.py` (CDR grafting), `backmut.py` (scoring/tiers — core deliverable), `minimal.py` (Vmin/CVI/matrix/V_SDR), `variants.py` (V0–V3 ladder), `learning.py` (ΔΔG calibration), `structure.py` (AF3 + PDB/CIF parsing + FreeSASA), `developability.py` (PTM scan), `report.py`/`report_docx.py`/`report_enhanced.py`.
- Scoring weights live in `scripts/humanize/config.py`; keep docs/scoring.md and docs/theory.md in sync when changing them.
- Bundled germline: `data/germline/human_germline_kabat.json` (373 V + 28 J, Kabat space), generated by `scripts/build_germline_kabat.py` from `abnumber_human_imgt.json`. NCBI download is used when present (takes precedence).
- Default germline strategy is `auto` (VH=cvi_best, VL=cdr_best); production-recommended variant is **V2** (T1+T2 back-mutations).

## Domain rules (never violate)

- Never revert VHH hallmark positions (Kabat 37/44/45/47) or CDR disulfide Cys; both are `KEEP_DONOR`.
- Never design back-mutations in CDRs or FR4 (J region is human by construction).
- Immunogenicity scoring counts only surface-exposed mismatches; buried mismatches are structurally tolerated.
- VHH detection: FR2 hallmark + single chain; check report warnings before recommending variants.

## Gotchas

- `scripts/custom_humanize.py` and `scripts/custom_germline_humanize.py` are gitignored (proprietary); README references the former — never commit them.
- `outputs/` is gitignored.
- Optional features need: `python-docx` (Word report), `biopython`/`abnumber`/`anarci` (server full mode), `freesasa` (buriedness — degrades gracefully), AF3/ProteinMPNN binaries (point at them via `--af3-mode/--mpnn-mode`; not installed by `install.sh`).
- Known correction: 4D5 mouse CDR3s are `DTYIH` (H1) / `SRWGGDGFYAMDY` (H3) — the widely copied "YDTYIH" is wrong (verified against 4 PDBs + HumAb25).
- For humanization requests, load the `antibody-humanization` skill (`.opencode/skills/antibody-humanization/SKILL.md`, registered in opencode.json) — it contains the full workflow and constraints.
