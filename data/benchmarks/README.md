# Benchmarks

- `humab25_parental_mouse.csv` — parental (mouse) VH/VL sequences of 25 humanized
  therapeutic antibodies (AntiCD28, Campath, Bevacizumab, Herceptin, Omalizumab,
  Eculizumab, Tocilizumab, Pembrolizumab, Pertuzumab, Ixekizumab, Palivizumab,
  Certolizumab, Idarucizumab, Reslizumab, Solanezumab, ...).
  Source: HuDiff dataset (TencentAI4S, https://github.com/TencentAI4S/HuDiff,
  DOI 10.5281/zenodo.16974296); the humanized counterparts are the approved
  antibodies. Used by tests/backtest_scale.py for scale/robustness validation.
